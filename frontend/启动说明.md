# 🚀 打卡APP启动指南

## 第一步：安装依赖

### 1. 安装前端依赖
```bash
npm install
```

### 2. 安装后端依赖
```bash
cd server
npm install
cd ..
```

## 第二步：启动后端服务器

**打开第一个终端窗口**，运行：

```bash
npm run server
```

或者：

```bash
cd server
npm start
```

看到以下信息表示后端启动成功：
```
🚀 服务器运行在 http://localhost:3000
📱 API 端点: http://localhost:3000/api
```

**⚠️ 注意：保持这个终端窗口打开，不要关闭！**

## 第三步：启动前端应用

**打开第二个终端窗口**（保持第一个终端运行后端），运行：

### iOS (macOS)
```bash
npm run ios
```

### Android
```bash
npm run android
```

### Web浏览器（用于测试）
```bash
npm run web
```

### 或者使用 Expo Go（推荐用于真机测试）
```bash
npm start
```
然后：
1. 在手机上安装 **Expo Go** 应用
2. 扫描终端中显示的二维码

## 📱 使用流程

1. **首次启动**：选择"匿名试用"或"手机号一键登录"
2. **创建目标**：进入"目标"页面，点击"+"创建打卡目标
3. **一键打卡**：在首页点击"一键打卡"按钮
4. **查看统计**：进入"统计"页面查看打卡数据

## ⚠️ 常见问题

### 问题1：后端连接失败
**现象**：看到"API调用失败，使用本地数据"的警告

**解决方案**：
- 确保后端服务器正在运行（第一个终端窗口）
- 检查 `src/config.js` 中的 `API_BASE_URL` 是否为 `http://localhost:3000`
- 如果使用Android模拟器，可能需要将 `localhost` 改为 `10.0.2.2`

### 问题2：端口被占用
**现象**：后端启动失败，提示端口3000已被占用

**解决方案**：
- 修改 `server/index.js` 中的端口号（如改为3001）
- 同时修改 `src/config.js` 中的 `API_BASE_URL`

### 问题3：依赖安装失败
**解决方案**：
```bash
# 清除缓存后重新安装
rm -rf node_modules
npm cache clean --force
npm install
```

### 问题4：iOS模拟器无法启动
**解决方案**：
- 确保已安装 Xcode
- 运行 `xcode-select --install` 安装命令行工具
- 在 Xcode 中打开模拟器

## 🎯 快速测试

如果想快速测试功能，可以：
1. 使用"匿名试用"登录（无需注册）
2. 在首页点击"一键打卡"测试基本功能
3. 进入"统计"页面查看日历热力图

## 📝 提示

- 后端使用内存存储，重启后数据会丢失（这是正常的，用于演示）
- 通知功能仅在真实设备上可用
- 如果后端未启动，应用会自动使用本地存储，功能仍然可用
